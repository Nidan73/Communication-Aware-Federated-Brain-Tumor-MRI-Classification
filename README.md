# Communication-Aware Federated Brain Tumor MRI Classification

This repository contains the code, manuscript sources, analysis scripts, and supporting assets for a communication-aware federated learning study on four-class brain tumor MRI classification.

## Main contents

- `paper_anonymous_submission/`: active anonymous IEEE manuscript and figures.
- `scripts/`: reproducibility, statistics, figure-generation, and validation scripts.
- `configs/`: experiment configuration files.
- `tests/`: synthetic and script-level tests.
- `paper_assets_final/`: final paper-facing tables and figures.
- `cluster_split_outputs/`: saved leakage-controlled split manifests and summaries.
- `duplicate_audit_outputs/`: duplicate-audit summaries and supporting outputs.
- `reproducibility/summary/`: multi-seed summary tables and manuscript-ready text templates.
- `reproducibility/statistics/`: paired statistical-analysis outputs.

## Not committed

The Git history intentionally excludes local datasets, Python environments, checkpoints, cached pretrained weights, large generated training outputs, and temporary manuscript build artifacts.
